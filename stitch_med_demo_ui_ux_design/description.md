---

1. Главная страница

· Быстрый поиск/карточки: «Запись к врачу» (ведущий на выбор специалиста), «Наши центры», «Личный кабинет (демо)».
· Блок с популярными специальностями (терапевт, хирург, ЛОР — клик → страница врачей с фильтром).
· Кнопка вызова личного кабинета (без авторизации).

2. Личный кабинет (демо-доступ)

· Данные пациента: Имя, пол, дата рождения (заглушка, можно редактировать только в демо-режиме).
· История посещений (список: дата, центр, врач).
· История анализов (название, дата, ссылка на «результат» — PDF-заглушка).
· Кнопка «Записаться» (ведёт к выбору направления/врача).

3. Страница медицинских центров

· Формат: карта (клик по метке) и список карточек под ней.
· В карточке: название, адрес, график работы, кнопка «Выбрать» (запоминает центр для записи).
· Фильтр/поиск по метро или улице (для демо — просто поиск по названию).

4. Страница врачей

· Фильтр по специальностям (выпадающий список или плитка фильтров).
· Карточка врача: фото (заглушка), ФИО, специальность, стаж, рейтинг (звёзды-заглушка).
· Кнопка «Записаться на приём» → переход на форму записи с предвыбранным врачом.

5. Страница записи (гибкая логика)

· Два режима переключения: «Запись к конкретному врачу» / «Запись по направлению (специальности)».
· Сценарий А (к врачу): выбор врача из списка → показ его свободных слотов (демо-слоты: завтра, послезавтра 10:00, 12:00).
· Сценарий Б (по направлению): выбор специальности → выбор любого врача этой специальности → слоты.
· Виджет выбора даты (календарь) и времени (список слотов).
· Итоговая форма: ФИО, телефон (демо, данные не сохраняются реально), кнопка «Отправить заявку (демо)» → всплывает сообщение «В демо-режиме запись не отправлена».

6. Вспомогательные страницы

· 404 / не найдено (стандарт).
· Успех / ошибка (после отправки формы).

---

Навигация и переходы (PWA)

· Нижнее меню (табы): «Главная» → «Центры» → «Врачи» → «Кабинет».
· Из карточки врача/центра → кнопка «Записаться» → на страницу записи.
· В форме записи: хлебные крошки (Главная → Врачи → Иван Иванов → Запись).
· Личный кабинет → «История посещений»/«Анализы» (отдельные страницы с возвратом в ЛК).

Бэкенд (минимальный, демо)

· Статические JSON-заглушки для списка центров, врачей, слотов.
· Отправка формы записи — просто POST с эмуляцией задержки и ответом 200.
· PWA Service Worker только для кэширования статики (не для офлайн-записи).

Главная страница (демо PWA)

1. Верхний блок — приветствие и статус

«Добро пожаловать! Это демо-версия»

· Иконка календаря → «Активно: Нет ближайших записей» (или заглушка «Есть запись 15 мая, 10:00» — можно переключать в ЛК).
· Иконка анализов → «Новые результаты (2)» или «Анализы: всё готово» / «Нет новых».
· Кнопка «Обновить статус» (имитация синхронизации).

2. Блок быстрого действия (FAB-зона)

· Записаться к врачу (крупная кнопка, акцентный цвет)
· Мои анализы (ведёт в ЛК, раздел анализов)
· Наши центры (на карту/список)

3. Ближайшая запись (если есть — в демо показывать пример)

«Ваша ближайшая запись: 15 мая, терапевт, пр. Мира 10»
→ Кнопки: «Отменить» (демо, спросить «Вы уверены?») / «Перенести»

Если записи нет — показать:

«У вас пока нет записей. Хотите записаться?» + кнопка «Записаться».

4. Важные новости и акции (карусель или 2–3 карточки)

Примеры для демо:

· Скидка 20% на первичный приём терапевта до конца месяца.
· Бесплатный чекап для новых пациентов.
· График работы в праздники — ссылка на страницу центров.
  → Каждая карточка — либо просто информационная, либо с кнопкой «Записаться».

5. Готовые результаты анализов (сводка)

Показывать даже в демо последние 2–3 аналита:

· «Общий анализ крови» — готов, смотреть (PDF-заглушка)
· «ТТГ» — готов, смотреть
· Кнопка «Все анализы» → в ЛК

6. Специальности / популярные врачи (плитка 2×2 или 3×2)

· Терапевт
· ЛОР
· Окулист
· Хирург
  → По клику — страница врачей с фильтром.

7. Баннер «Не нашли что искали?»

«Позвоните нам: +7 (XXX) XXX-XX-XX» или «Заказать обратный звонок» (демо-форма).

8. Нижний навигационный бар (как во всём PWA)

· Главная
· Центры
· Врачи
· Кабинет

---

Что показывать при первом заходе?

· Приветственный попап или баннер: «Это демо, но вы можете посмотреть, как работает запись и личный кабинет».
· Все данные — примеры, кнопки ведут на демо-слоты.
